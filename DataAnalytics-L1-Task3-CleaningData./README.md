# Task 2 – Data Cleaning

## Oasis Infobyte Data Analytics Internship

### Project Overview

This project focuses on cleaning and preparing a cafe sales dataset for further analysis. The dataset contained missing values, invalid entries, duplicate records, inconsistent data types, and other data quality issues.

### Objectives

- Identify and handle missing values
- Remove duplicate records
- Correct data types
- Standardize categorical values
- Identify potential outliers using the IQR method
- Create a clean, analysis-ready dataset

### Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

### Data Cleaning Process

1. Loaded and inspected the dataset.
2. Identified missing and invalid values.
3. Converted invalid entries such as `UNKNOWN` and `ERROR` into missing values.
4. Handled missing numerical and categorical values where appropriate.
5. Removed duplicate records.
6. Standardized text and date formats.
7. Corrected data types.
8. Identified potential outliers using the IQR method.
9. Exported the cleaned dataset as `cleaned_cafe_sales.csv`.

### Files

- `data_cleaning.ipynb` – Complete data cleaning notebook
- `dirty_cafe_sales.csv` – Original dataset
- `cleaned_cafe_sales.csv` – Cleaned dataset

### Outcome

The dataset was cleaned and transformed into a more consistent and analysis-ready format, improving its quality for further data analysis.
